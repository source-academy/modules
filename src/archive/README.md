# Source Academy Modules Archive

This folder contains modules that are considered archived, that is modules that are no longer in active deployment, but whose source code is
retained for future reference.

Bundles and tabs that were not migrated to Conductor were archived here when the non-Conductor module system was removed
(source-academy/modules#1001). To bring one back, port it to a Conductor plugin (see `src/bundles/rune` or `src/bundles/repeat`) and move it
back to `src/bundles` (and its tab to `src/tabs`).
